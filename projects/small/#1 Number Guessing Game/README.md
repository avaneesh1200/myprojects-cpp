## Build Instructions
Built `with g++ (via mingw)` you can use any compiler you feel comfortable with\
G++\
`g++ Main.cpp`\
<br>

MSVC\
`cl.exe Main.cpp`\
<br>

Clang\
`clang++ Main.cpp`\
<br>

Zig C ++\
`zig c++ Main.cpp`\
<br>

> If you want a custom file name just add the -o flag with your filename for example: `g++ Main.cpp -o game

`g++ Main.cpp -o game` <br>
> Use the /Fe flag instead of -o <br>

`cl.exe Main.cpp /Fe:game` <br>
`clang++ Main.cpp -o game` <br>
`zig c++ Main.cpp -o game` <br>

>it produces game.exe (if you are on windows)
